# Kiếm Tu prototype assets

Copied from the user-provided `kiem_tu_sprite_test_64x64/kiem_tu_sprite_test` pack in this repository.

- spritesheet.png: original 6×11 atlas, 64×64 cells; unused padded cells are excluded by metadata.
- metadata.json: original frame counts, FPS, loop flags and feet anchor (32,58).
- portrait.png: original frames/idle/00.png for the HUD and left panel.

All three races currently share this prototype appearance; ground markers retain race colours. This changes rendering only. Unused animations (meditate/fly_sword) remain available in the pack but do not grant gameplay abilities.
